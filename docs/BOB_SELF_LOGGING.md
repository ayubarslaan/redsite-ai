# How to Have Bob Log Its Own Usage

After each Bob session, use this exact prompt to have Bob generate the log entry for you:

---

## The Self-Logging Prompt

Copy-paste this into Bob after each implementation session:

```
I need you to generate a log entry for my IBM AI Builders Challenge submission.

Here is what just happened in this session:
- My prompt to you: [PASTE YOUR PROMPT]
- Files you generated: [LIST FILES]
- Key functionality: [DESCRIBE WHAT THE CODE DOES]
- My refinements after you generated it: [DESCRIBE CHANGES]

Please output a markdown log entry in this exact format:

## Session [N]: [TODAY'S DATE] — [BRIEF TITLE]

**Prompt to Bob:**
```
[EXACT PROMPT]
```

**Bob's Output:**
- Files generated: [list]
- Key features: [description]

**Human Refinements:**
- [What was changed]

**Lines of code:**
- Bob-generated: [estimate]
- Human-refined: [estimate]
```

Then copy Bob's output directly into `docs/BOB_USAGE.md`.

---

## Why This Works

1. **Authenticity** — The log entry is generated by Bob itself, not fabricated
2. **Consistency** — Same format every time
3. **Evidence** — Judges can see Bob actually produced the log content
4. **Git history** — Each append is a real commit with a real timestamp

---

## Recommended Git Workflow

```bash
# After each Bob session:
git add docs/BOB_USAGE.md [new files]
git commit -m "Session N: [feature] via IBM Bob"

# This creates a timestamped chain of Bob usage evidence
```
